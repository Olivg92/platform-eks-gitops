# Runbooks

One file per alert. Each answers the same questions, in the order someone woken up at 3am asks
them: what is broken, for whom, how bad, what to do now, and what to look at once it is calm again.

Every alert generated by Sloth carries a `runbook_url` annotation pointing here, so the link is one
click away from the notification.

| Alert | Runbook |
|---|---|
| `DemoApiAvailabilityBudgetBurn` | [demo-api availability](demo-api-availability.md) |
| `DemoApiLatencyBudgetBurn` | [demo-api latency](demo-api-latency.md) |
